# 外观补全与物理轨迹回传渲染

建立显示资产、准备最终 real/sim 交付或排查“物理成功但图像很假”时读取。第一步只验证静态首帧；第二步可先渲染明确标注的运动拟合预览，最终物理画面必须绑定对应的原生物理轨迹。先说明图像来源和用途，再比较画质。

## 1. 用少量样帧建立外观基线

选择能看清主要表面、抓取接触和不同遮挡关系的代表时刻，检查所有可用视角，包含腕部近景。按画面占比、差异强度与任务相关性排序：机器人/工具和目标物 → 桌面、容器等大面积表面 → 主要背景轮廓 → 小型陈设。不要以“背景允许近似”为由遗漏占据大部分画面的桌面材质、柜体或墙面。

区分误差来源：轮廓/遮挡和尺度先查几何；整体构图先查相机和输出尺寸；色块、反射、阴影和空白背景查显示资产。比较参考时匹配相机、时间、分辨率、裁切和渲染用途，不把 MuJoCo 诊断图与 Blender 精细图的差距归因于重建或模型能力。

## 2. 材质、纹理、背景与灯光

|层面|最低完成内容与检查|
|---|---|
|机器人、工具和目标|区分金属、喷漆、橡胶、塑料、陶瓷、玻璃等可观察类别；配置基础色、粗糙度、金属度，必要时透明/折射。先核对法线与平滑，防止圆柱和金属表面呈现错误折面。|
|大面积表面|桌面、墙面、柜体等补具有合理尺度的纹理；需要时增加轻微法线/凹凸。优先复用现有纹理和程序纹理，检查重复、拉伸、接缝及过强噪声，不把贴图分辨率当作唯一画质指标。|
|背景和陈设|补跨视角可见且显著影响构图的柜体、门框、台面延伸、瓶罐、线缆等轮廓；先确定核心物体选择，非显著细节可明确省略；所选物体须为完整有厚度结构，不用点云后处理薄面冒充完成。同一对象在所有视角共享位置，不为每个相机搭独立背景。不可见区域允许合理近似并标明。|
|灯光与色彩|匹配主要光源方向、软硬阴影、环境亮度和整体曝光/白平衡。保留物体接触阴影、容器内遮蔽和金属反射；合理使用面积光与环境光，避免用极端曝光掩盖材质错误。记录色彩管理配置。|

纹理来源标为源图提取、资产自带、程序生成或估计。源照片提取静态表面纹理时纠正透视、尽量移除烘焙阴影/高光，遮罩机器人、移动物体、箭头/界面叠加和遮挡者，避免复制“第二个机器人”或双重阴影。单视角投影纹理必须检查其他视角；新显露区域保持诚实近似，不能把目标/接触画面直接贴到背景以制造对齐。

显示和碰撞通过稳定对象ID、局部坐标与父子变换关联。外观倒角、瓶盖、标签等不必逐一增加碰撞；若新增细节改变了操作区实体轮廓、间隙或支撑，则更新相应碰撞并回归。粗糙度/金属度不等于摩擦/刚度，不能互相替代。

## 3. MuJoCo → 原 Blender 显示场景

- 保留原显示工程、材质、贴图、灯光和静态背景。导入本次接受或明确标注失败的原生轨迹，保存到新工程；不要重新从简单 MJCF 生成色块场景而丢失原有外观。
- 建立 `body/link ID → Blender object/root → local visual transform` 映射。按来源处理世界/局部变换、单位、父子逆矩阵和网格偏置；替换旧动作、驱动器、约束或刚体缓存对动态对象的控制，防止旧动画覆盖新轨迹或父子链重复施加变换。附属视觉部件随对应刚体，线缆等辅助动画检查连接但不冒充求解结果。
- 机器人、目标和物料均使用同一条原生状态序列。对源时间戳选择物理样本或插值；平移与旋转采用有记录的方法，四元数保持半球连续，避免默认曲线插值越界。快速接触应保存/使用更密的状态，并检查插值后的间隙和穿入；不能靠跳帧、改杯轨迹或改落点修饰物理失败。
- 固定相机读取已核验的标定；腕部相机跟随原生机器人安装链和固定手眼变换。保留焦距、主点、像素宽高比、传感器约定、分辨率、裁切及畸变处理说明；不能统一输出成另一种宽高比却仍声称视角完全相同。
- 在起止和关键交互时刻比较 Blender 求值后的机器人、物体和相机变换与原生记录，记录误差及源时间映射。所有视角按各自时间戳映射，不默认相同帧号就是同步时刻；额外稳定段单列。
- 保存可编辑工程后重开少量样帧复核。图像必须能够由保存的工程及明确渲染入口重现；只在渲染前临时覆盖姿态、却把旧动画留在交付工程中的做法不合格。外部贴图/网格打包或使用可解析相对路径，并检查缺失资产。

## 4. 渲染、验收与停止

几何/接触迭代用便宜预览；最终 Blender 输出使用满足目标材质与光照的渲染器和设置。反射、透明或间接光明显时优先测试 Cycles；Eevee 也可在样帧达到用途时使用。按当前设备选 CPU/GPU 后端，不硬编码其他机器的 OptiX/Metal。先一张预热测时，再调整样本数与降噪；不把某次的 24 samples、Blender 版本或分辨率当通用要求。

对全部要求的视角先检查代表样帧：材质是否读对、纹理是否错位、阴影是否合理、背景是否遗漏、腕部近景是否穿帮。用同时间/视角的 real 与新渲染比较；已有参考可另外列出并注明其来源、压缩、时间取整及是否物理回放。若版式影响比较，先统一呈现而不是调整场景。

五问的“最大差异”和“逼真度”明确记录外观完成项、主要残差及本轮是否阻塞；低成本预览不能作为最终外观通过证据。首次样帧通过后只修阻塞差异，复用用户认可的外观，不因小背景偏差无限迭代。样帧检查不替代必要的逐事件五问与几何扫描。

只请求关键帧就交付关键帧；请求视频再完整渲染/编码。修改材质、纹理、灯光或纯显示背景通常仅使相关图像失效，不重跑物理；相机变化重查投影，改变操作实体几何则同时使相关接触检查失效。缓存键包含显示工程、全部外部资产、原生轨迹、相机、时间映射和渲染配置。

## 5. 第 8 环节默认输出 Real / Blender / MuJoCo 三方对照

第 8 环节默认输出三方对照，复用当前原生 rollout 与已验证 Blender 图像，不重跑物理。默认使用真实事件代表关键帧，context 与已触发问题的邻域诊断另列，保留全部可用视角，三列共用源索引；记录源帧、Blender 帧、原生状态行和采集时间，不把播放帧率当采集时间。

MuJoCo 画面从保存的同帧状态求值后渲染；这是已完成原生执行的状态可视化，不是新的执行证据。相机使用 Blender 求值后的世界变换与有效投影矩阵，核对坐标轴、焦距、主点、像素宽高比及裁切；原生渲染器不支持的投影参数可用有记录的过扫描重采样实现，但不能对真实/模拟图像独立平移以掩盖场景误差。

明确区分 Blender 精细材质/核心背景与 MuJoCo 原生显示/碰撞代理；避免机器人 visual 与 collision 重叠显示，同时保留仅由碰撞几何表示的任务物。调整渲染相机后同步随相机灯光，照明变化单列且不改变动力学。输出可切换帧的三方页面、代表帧总览和来源清单；核验覆盖与可解码性，抽查首帧、抓取、任务动作及释放。图像齐全不代表所有五问已通过。

## 6. 第二步第 8 环节：外观优化与输出

在第二步第 8 环节，原生轨迹回传 Blender 后执行：①固定几何与相机；②调整材质；③补充纹理；④调整灯光；⑤多视角预览复核后提高最终采样。第一步保留可辨认的基础外观，第 4 环节继续执行五问并记录外观差异；系统性外观优化在第 8 环节完成。几何或相机有阻塞问题时返回对应环节，不用打光补偿。每轮只改可解释的一组参数，用首帧、抓取、任务动作、释放等代表时刻的全部视角共同复核。

1. 固定色彩管理和曝光基准，区分材质颜色与光照色偏；整体过亮先查曝光/光强，不先把所有材质调暗。
2. 按物体类别设置基础色、金属度与粗糙度；先让塑料、橡胶、喷漆和金属可辨认，再调高光宽度及强度。参数是估计，不能声称从 RGB 唯一辨识。
3. 大面积表面补共享 UV 或物体坐标程序纹理，校正尺度、方向和重复；小幅 bump/normal 提供微结构，不改变实体接触几何。源图纹理先纠正透视并去除移动物体及明显烘焙光影；所有相机共用同一纹理。
4. 根据阴影和反射估计主要面积光位置、尺寸、方向与能量，配合环境光。先匹配整体明暗与阴影方向，再细调反光；不要逐视角搭不同灯光。
5. 少量样本、降噪预览比较实例区域颜色、纹理尺度、高光和接触阴影；五问记录最大残差。可用实例内颜色统计辅助比较，但原始全图像素误差不能代替空间判断。通过后提高最终采样并复核，增加 samples 只降噪，不修正错误材质。

### 第 8 环节的前景／背景纹理适配闭环

本环节覆盖场景中全部已选实体：**前景机器人、夹爪、工具、交互物体与物料；桌面和支撑物；核心背景的桌椅、柜体、墙面、地面及其他已建模物体**。不能只优化桌面便把全场景标为完成。按对象 ID 建立外观覆盖表，记录材质区域、真实证据帧/视角、纹理来源、UV/尺度、修改、检查状态与剩余差异。相同材质可共享资产和参数，但逐对象核对映射。纯色塑料、玻璃或干净金属可通过颜色/粗糙度/透射优化，不强行贴上木纹、污渍或生成图。

1. **观察与素材筛选**：在真实多视角中识别各物体的材质类别、纹理方向、尺度、磨损和反光。按需要从 Poly Haven 等合法来源下载相似 PBR 素材，保存资产页面、许可、分辨率与校验和。先看缩略图筛选，再下载适当分辨率；偏深、过旧或纹理类别不符的素材先换候选，不能靠强烈调色硬套。
2. **结合生成能力适配**：库素材不够匹配时，用其作为编辑底图、真实物体区域作为外观参考，生成独立候选。优先修正板缝、织物纹理、细小划痕、涂层与局部色差；明确目标为平展、无透视、均匀照明的 base color，按用途要求可平铺。去除阴影、高光、机器人、其他移动物、桌面标记和界面叠加，不能直接把含场景内容的实拍图贴回物体。每个材质类别分别适配，不把一张生成纹理铺给所有前后景物体。
3. **PBR 一致性与来源**：颜色贴图用 sRGB，roughness/metallic/normal 等数据图用 Non-Color，核对法线约定。生成颜色图不会自动得到匹配的新法线/粗糙度；旧图仅可作为有说明的弱微结构，若板缝或凸起变化需更新对应图。不能把颜色明暗直接当真实高度或宣称得到实测材质。记录下载底图、参考帧、生成说明和候选哈希。
4. **绑定与尺度**：所有视角共享同一物体材质。静态物体可用共享米制投影；运动物体和机器人使用随物体/连杆运动的 UV 或局部坐标，避免纹理在运动中滑动。检查各面的方向、比例、重复、接缝和凹凸强度，尤其是容器内外、夹爪近景和运动后新显露的背面。生成前景与背景资产均保持可编辑、可替换。
5. **光照与多视角复核**：保持几何、相机和原生动作，先比较真实／原素材适配／生成候选，再调整材质与统一灯光。覆盖事件代表关键帧的全部所需视角，并对调整触发的邻域复核受影响项，前景检查接触、遮挡及高光，背景检查大面积色调、纹理尺度与一致性。过亮、过饱和、假板缝或风格不符时回退或改下一候选；不能以生成成功或纹理更丰富替代“更贴近实拍”。五问更新受影响项，未检查对象不标通过。
6. **保存与输出**：样帧达到本轮等级后再提高采样；打包贴图或使用可解析相对路径，重开工程验证图像资源、对象/相机/动作绑定。交付外观覆盖表、素材/生成来源、同帧前后对照、工程及剩余差异。少量预览帧仅说明预览覆盖，不替代全事件验收。MuJoCo 未同步的着色特性单列，不能把 Blender 外观升级说成 MuJoCo 材质已更新。

节省成本：按画面影响排序处理前后景，共享同类素材，先低分辨率筛选和少量样帧预览，只重渲染受影响视角/帧；保留完整对象覆盖，不因优先级低而静默遗漏。纯外观修改不重跑物理；改变实体几何或接触表面则返回相应回归。

MuJoCo 迁移保留核心背景显示网格，按材质拆分子网格并保留对象 ID/世界变换；显示设置 `contype=0, conaffinity=0`，质量为零。必要碰撞代理使用独立组，避免与显示重复渲染。无法直接迁移的程序材质可烘焙为 UV 纹理；只迁移基础色时须明确降级。新增碰撞代理后检查全轨迹状态中的接触变化；若影响动力学，重做相关物理回归。纯显示修改只重查绑定、投影和渲染。
