# 第二步：性能与增量执行

仅在耗时异常、复杂接触/多物料、恢复长任务或明确优化时读取。先区分物理求解、Python 扫描、数据写入、渲染/编码与模型上下文成本；不要把一次总耗时归因给某个未经隔离的参数。

## 开跑前：用短基准阻止长时间盲跑

在相同初态和模型版本上预热，分别测 `mj_step`、接触统计、状态保存的耗时。选择初始化、稳定抓持、物料相撞/落定等代表阶段，返回步数、墙钟秒、物理秒、接触数/约束规模、警告与完整运行估算。样本长度按成本调整，不固定跑满几千步。

慢时依次排查：

1. **重复支撑接触**：容器底面、壁片底边和桌面重合，可能生成大量冗余约束。让明确的底部代理承担静置支撑，检查壁片与底部的重叠/接缝；任何近似仍需满足当前几何容差，保留侧壁碰撞和空腔，不能直接屏蔽物体—桌面接触。
2. **碰撞表示**：薄片、圆柱、密集小物料选择原语或简化凸网格做短段对照，比较耗时、穿入与任务行为。网格不普遍比原语快，改表示也不保证消除穿入。
3. **不必要的约束和精度**：按物理用途选择接触维度、材料参数与求解设置。更少接触维度、较低精度或更大步长会改变物理，须回归；不能仅以变快或无警告接受。
4. **Python 热循环**：缓存 body/geom ID、角色映射和不变变换，避免每步解析名字或读取 JSON。全步数值检查返回极值和异常区间；只在关键帧/异常窗口保存详细接触列表。按需记录小型二进制轨迹，避免每步重复巨大文本。

多工况并发应在单次成本已可控、CPU/内存允许后使用；不要同时跑多个未知成本的重接触候选。性能检查不是代理并行授权。

## 候选、缓存与恢复

- 先用当前失败事件附近的短段区分候选，方向有效再延长到后续稳定边界。改变闭合量不必立即验证全段落料；改变圆片碰撞则需覆盖堆叠、出杯和撞碗。
- 缓存仅在输入依赖一致时复用。模型/碰撞/物理参数变化后，不能把旧物理检查或旧物料状态当新版本结果。材料改变不必重跑动力学，相机改变只使相应图像/投影评测失效。
- 局部续跑若依赖此前接触历史，需要可恢复的完整积分状态、控制相位、时间和随机状态；只有 qpos/qvel 的截图不保证等价。首次使用恢复路径时与连续执行验证一致。模型改变后先判断恢复状态是否兼容，不兼容则重跑前缀。
- 长跑定期写小型进度记录与可用检查点，包含已完成物理时间、源索引、当前事件、耗时、最新异常。失败先保存上下文再结束候选；尚可能恢复的接触过渡不能直接早停为失败。
- 确定候选后保留一次从最终磁盘模型开始的完整回归。局部检查省时间，不能代替最终全程；无需无理由反复全程复验。

## tokens 与交付成本

首读当前清单和摘要；需要具体值时按字段抽取，不打印整段轨迹、全部 timestamps 或历史脚本。默认只回传计数、极值、失败区间与少量关键帧证据。可复用脚本先查接口/硬编码适用性，不每轮全文加载。

保留所有要求的关键帧×视角×五问。模型只写变化项和新空间判断，未失效项用共享证据/`inherited_from` 引用；生成器展开完整表格。不能为了省 tokens 删除必要视角、用未看过的邻帧代填，或把未知状态写成通过。

物理尚未合格时只渲染诊断帧/短片；最终需要视频才批量渲染，并从缓存图像生成多种排版。最终完整解码一次，再抽查源图对应；编码样式变化复用相同原生帧。资产和帧哈希写入清单，后续按变更依赖更新，避免同一轮多次扫描相同大文件。

建议摘要集中包含 `model_hash / config_hash / stage / completed_steps / physics_seconds / wall_seconds / task_status / geometry_status / warnings / failure_intervals / output_paths`。各场景可复用现有字段，不强制额外格式或引入一套新框架。

## 本仓库实测经验：不是通用参数

- 木块投杯：排查对准和开口后，额外闭合 0.03 rad 改善持续承载；不能跳过诊断给所有新场景加同一偏移。
- 双视角球体入盘：抓取已成功，但理想球体持续滚动；校准滚动阻力改善落点，无需重建机器人或修改全部动作。
- 倾倒场景：35,235 个物理步的一个旧候选约 3,063 s；调整重复底部接触、圆片碰撞表示及部分接触参数后的候选约 59.4 s，约快 52 倍。非隔离基准，硬件负载可能不同，不能把全部收益归因于单项修改或承诺其他场景同等提速。
- 同一新候选倒入 18/18 个圆片，但最大穿入约 2.86 mm，仍超出该场景既定 2 mm：任务结果通过不等于完整验收通过。
- 倾倒旧支撑评测逐点要求 >0.01 N，漏掉许多小接触共同承担约 0.44 N 重力；应按支撑关系聚合，而非抬高摩擦或再次调轨迹。
